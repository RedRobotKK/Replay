## 1. Executive Summary & Vision

### 1.1 Product Vision
**Project Buffy** is an open-source, local-first, high-performance **Context Operating System (CxOS)**. It runs natively as a secure background daemon on a workstation, serving as a drop-in middleware layer between autonomous development environments (e.g., Cursor, Claude Code, Aider, custom agent loops) and upstream Large Language Model (LLM) inference providers.
