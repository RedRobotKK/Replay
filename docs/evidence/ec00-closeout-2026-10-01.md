# EC-00 / RPL-C034: closeout

**The audit trail for one compression defect, from discovery to repair to
reconciliation. Nothing here reopens a question.**

Final commit `adefeeb`. Production repair `6794522`. Evidence baseline
`8582262`.

---

## The finding, in one sentence

**Replay already possessed the token evidence. The defect was discarding known
token evidence because an unrelated dollar-price lookup failed.**

---

## What was changed

**One production file, `cmd/replay/cost.go`, at three sites.**

| Site | Change |
|---|---|
| `costUnit` | an explicit `Unpriced` flag: token quantities known, dollar quantities unavailable. Zero dollars is deliberately NOT the representation |
| the session gate | flags instead of dropping, so the unit reaches `cache.put`, and asks the price table instead of inferring priceability from a cost of zero |
| `RebilledTokens` | assigned outside the price branch |
| the warm path | reconstructs the disclosure from the serialized flag, the same replay `join.addCached` performs one line above it |
| `summarise` | dollar statistics over priced rows only, so an unpriced row's zero cannot move the median |

Four test files: `claim_coldwarm_test.go` (new oracle), `claim_rebilled_test.go`
and `claim_ranking_test.go` (pins converted to regressions),
`claim_refusal_matrix_test.go` (MX3 annotated as the regression case).

## What was deliberately NOT changed

- **`worstByRebilledTokens`.** RB4 proved it discriminates; it was downstream
  of the collapse. The evidence predicted this and it held.
- **The seven other consumers of the price boolean.** Censused from source,
  never measured at a user-visible boundary. Untouched on purpose.
- **No manual cache-version bump.** `unitSchema()` reflects `costUnit`'s json
  tags into the index key, so adding a field discards every older index. The
  existing mechanism was sufficient and was not duplicated.
- **`summary.tasks` still means priced rows**, so
  `TestAnUnpricedSessionIsExcludedAndCounted` passes unmodified. No existing
  contract test was weakened, rewritten or bypassed.
- **No evidence file was edited or deleted.** The three earlier EC-00 files
  stand as the before state, including the withdrawn repair.

## The claim that did NOT move

**RPL-C031 stays REFUTED, and this is the most important line in the closeout.**

It concerns **record** granularity within a session. The repair works at
**session** granularity. A session holding two priceable and two unpriceable
records has a priceable model on its first request, is not flagged, and
discloses nothing.

**Re-measured after the repair rather than inferred from it:** MX3 and MX10
both still report `unpriced=0` with no disclosure. A record-level counter is a
separate change and was not made.

## The evidence boundary, held

`docs/TOKEN-PRICES.md:53` — "An unpriced model must never count as zero" — is
**satisfied for the re-billed token count at `replay cost` and `replay since`**
and **NOT established anywhere else.**

**A source census does not become a user-visible verification by being quoted
twice.** The nine compliant call sites still use at least four different
conventions, so there remains no shared contract in code, only a shared
document.

## Method notes worth keeping

Three of this investigation's turns were corrections to its own work, and each
was found by a control rather than by review:

1. The first attribution named `cost.go:717` alone. **A surviving mutation
   disproved it** — the quantity is gated twice and control never reached 717.
2. The first ranking fixture omitted `--per-task`, read an absent array, and
   two missing values arrived as two zeroes. **The control arm caught it**
   before any conclusion was drawn.
3. The first repair satisfied every behavioural invariant and **broke the
   disclosure on the warm index path.** It was withdrawn, and the boundary grew
   from two sites to three.

The eight-site census was also retracted: most flagged sites gate only
dollars, which is correct, and two carried presence flags the detector missed.
