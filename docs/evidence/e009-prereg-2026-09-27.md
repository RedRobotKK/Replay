# E009 preregistration: does a sufficient anchor sustain or terminate investigation?

**Written before any E009 trial runs, before the pre-flight gate is executed,
and before its output is seen.** The D anchor below is fixed by this document
and may not be changed after its output is observed.

## Why this experiment

E008 found that the correct anchor HURT and the stale anchor did not: arm A
(no anchor) detected 8/10, arm B (correct anchor) 4/10, arm C (stale anchor)
10/10, with C against B at Fisher one-sided p = 0.005.

Its restated mechanism:

> An anchor that names a performable check induces closure at that check. If
> the check cannot falsify the claim, the anchor suppresses investigation and
> is worse than no anchor at all.

E008 states plainly what it could not separate: arm B's anchor was **correct in
direction and insufficient in power**, and no arm carried a *sufficient*
anchor. The word "sufficiency" carries the whole mechanism claim and has never
been manipulated.

Until an arm carries a sufficient anchor, "satisfiable anchors terminate
investigation" is indistinguishable from "any named check terminates
investigation". Those two imply opposite designs.

## Hypotheses

- **H-SUFF.** Termination is governed by whether the named check can falsify
  its claim. A sufficient anchor yields high evidence arrival and a LOWER
  call-to-evidence index than no anchor, because one decisive check replaces a
  broad search. Predicts **D > B**, and D at or near C.
- **H-DELEG.** Naming any performable check delegates judgment and terminates
  search regardless of sufficiency. Predicts **D ~ B < A**.

Both are reportable. H-DELEG is the outcome that falsifies E008's mechanism
statement, and it is named here before the data exist.

## Arms

n=10 each, 40 trials, interleaved A,B,C,D within every round. All four arms
carry the identical 3-row claims table and the identical false claim 2. Only
the anchor column varies.

| arm | anchor | role |
|---|---|---|
| A | absent | addressability baseline |
| B | `git branch -a`, then look for a Grok reader on other branches | replicates the E008 suppression effect |
| C | `cmd/replay/grok.go` header comment | **positive control**, known near-ceiling |
| **D** | `git log --all --oneline -- cmd/replay/grok.go` | **the new arm**, intended to be sufficient |

All four arms are re-run on the current substrate. Comparison against E008's
historical numbers is **invalid** and is not performed: E007 demonstrated this
substrate drifts, and a drifted substrate at ceiling cannot discriminate any
hypothesis. Arm C exists so that a low D can be distinguished from a substrate
that has stopped discriminating.

## Pre-flight gate, mandatory, before any trial

Arm D's anchor is a hypothesis about the substrate until it is executed against
that substrate and its output inspected. The gate records:

1. substrate HEAD
2. target identifier, taken from the frozen scorers and not reinvented
3. the exact command
4. its exact output
5. whether the target appears in that output
6. whether the command is executable with the experimental agent's tool set
7. whether the output is **actual target evidence** rather than a name or
   reference to one
8. whether the command could falsely appear sufficient while failing to expose
   the target evidence

Plus the leakage checks already specified by the E007 addendum, re-run
unchanged: `grep -rl "astra-launch-surface\|6074075"` over the working tree,
and `git grep` for the same at the substrate HEAD. Both must return zero.

**PASS** requires that the exact preregistered D command surfaces the target
evidence AND that the substrate does not expose the target independently.
**FAIL** on any other outcome. On FAIL, D is not redesigned in the same sitting
as the failure, and no trial runs.

Item 7 is load-bearing and is the error E007 already made once. The frozen
scorer's target regex `astra-launch-surface|6074075|912dd8` matches the branch
NAME, and a branch name appearing in output is a command-shape proxy, not
evidence that a second Grok reader exists. An output containing only the name
does not satisfy item 7.

## Dependent variables

Primary: **evidence arrival**, the target present in a `tool_result`. Never the
scorer's `searched` boolean, which is a command-shape proxy, and never a
transcript string count. Both produced withdrawn claims in earlier rounds.

Secondary: call-to-evidence index; detection via `score_e003.py` unmodified;
grok-directed commands; grok commands reaching beyond the working tree; total
calls.

Declared now, new in E009: **check-performed** (the anchored command was run)
and **check-discharged** (the claim was annotated settled after running it).
E008's arm B failed by performing the check superficially and then discharging
it; only a variable separating those two can confirm that mechanism.

## Controls

Identical prompt, model `claude-sonnet-5`, tool set Bash/Read/Grep/Glob,
substrate HEAD, and arms interleaved within round so contamination cannot align
with an arm. Cursor byte lengths recorded and kept as close as the anchor text
permits.

## Sample and stopping

n=10 per arm, 40 valid trials, fixed in advance. No optional stopping, no
peeking, no trials added after results are seen. Abort conditions: the
pre-flight gate fails, or contamination exceeds 25% of launches, in which case
the harness limitation is the finding and the run is abandoned rather than
patched.

## Validity

E007/E008 discipline unchanged. Every transcript scanned for
`cross-session-message` frames before scoring and without reference to outcome;
contaminated and memory-killed trials excluded per trial, preserved on disk,
and replaced to reach n=10 clean. Arm labels stripped before any manual
mechanism read. Scorers frozen before any transcript is read.

## Falsifier, registered

If D's evidence arrival does not exceed B's at Fisher one-sided p <= 0.05,
**H-SUFF is falsified** and E008's mechanism statement must be restated as "any
anchor naming a performable check suppresses investigation relative to none".

If arm C does not reproduce near-ceiling, the run is **inconclusive for
mechanism discrimination** and no comparison among A, B and D may be reported.

## Artifact preservation

Every trial JSON preserved, contaminated and memory-killed included. Validity
ledger CSV. Cursor hashes and byte counts, substrate HEAD, and the pre-flight
output recorded in the frozen result.

## What this preregistration does not claim

That durable state helps. That the mechanism is memory. That the effect is
improved task success. That any agent saw the contradiction and missed it;
the SAW-MISSED count across 21 re-analysed trials is zero. That a correct
anchor helps; that claim is withdrawn and is not revived here.

E009 measures one transition in the search path. A result here says nothing
about interpretation, contradiction detection or reconciliation, whose cells
remain empty for lack of variance.
