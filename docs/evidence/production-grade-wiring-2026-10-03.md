# Production-grade wiring: every dispatched surface through the shipped binary

**2026-10-03. Thirty-three surfaces, one production binary, forty frozen mutants built
into binaries of their own. One production repair. Nothing certified on effort.**

The runtime wiring gate (`cmd/replay/wiring_gate_test.go`) proved each surface in
process, through `dispatch()`. This phase asks the harder question: does the binary
a user runs reach the deciding code, does a registered check observe it, and would
that check go red if the code were broken? The answer is measured by
`internal/blackbox`, a `mutation`-tagged package that builds `./cmd/replay`, runs
every surface as a child process on its own `HOME`, and then builds each surface's
frozen mutants into binaries and requires the same checks to fail.

Labels: **OBSERVED** is what the binary printed or a test did. **READING** is what
that permits.

---

## 1. Discovery

**Mechanism.** `discoverSurfaces` parses the `dispatch()` switch in
`cmd/replay/main.go` (the same walk the wiring gate uses, re-derived here so the two
cannot drift). Every `case` is a surface; its entry function is the first `run*`
call in the case body. `TestBB_EverySurfaceHasABlackBoxSpec` fails when a dispatched
surface has no black-box spec or a spec names a surface that no longer exists: the
spec table is hand-written, the inventory is not, and the guard is the join.

**OBSERVED: 33 surfaces**, the same 33 the wiring gate found. None disappeared.

Per surface the matrix records the production entry (the exact invocation), the
dispatch line and entry function, the deciding code (the frozen mutant's file and
anchor), the production caller, the black-box checks, the oracle, the mutants
killed, the negative result and the status. `docs/evidence/production-grade-matrix.md`
is generated by the run and compared byte for byte by `TestBB_Matrix`.

---

## 2. Production reachability

Every row's "Production Caller" is the entry function `dispatch()` hands control
to, declared in a non-test file of `cmd/replay` (the wiring gate's
`TestWiringGate_EntryPointsAreInClosure` already fails otherwise), and every
"Black Box" cell is the real binary producing the expected effect: the chain
*real entry → dispatch → deciding code → observable effect* is observed, not
inferred, for all 33. Test-only reachability cannot pass this gate because the
test never links the package: it runs `replay` as a process.

Automatic detections that stand behind this: zero production callers of an entry
(`TestWiringGate_EntryPointsAreInClosure`); oracles outside the shipped closure
(`TestWiringGate_RegisteredOraclesRunInTheShippedClosure`); packages the binary
does not link (`TestNoNewlyUnwiredPackages`); surfaces with no E2E or no mutant
(`TestWiringGate_EverySurfaceIsWired`); surfaces with no black-box spec
(`TestBB_EverySurfaceHasABlackBoxSpec`); a mutant that survives the binary
(`TestBB_ProductionGrade`); a matrix that disagrees with the run (`TestBB_Matrix`).
Default-off paths are exercised with their flag on (`serve --loop-block`,
`--max-session-usd`, `--breaker-failures`), and `serve`'s refusal checks use a
second refusal behind the first so a build whose guard stopped refusing cannot
reach a listener.

---

## 3. Registered oracle and the negative test

Each surface is held to its `TestE2E_<Name>` test (in process) and, in this phase,
to the black-box checks run on the binary. The negative test is the catalogue: for
every frozen mutant whose `killedBy` names the surface's E2E test, the tree is
thawed into a scratch copy, the mutant applied, a binary built, and the surface's
checks plus its invalid-input probe run against it on a **fresh fixture set**. The
mutant is killed only if at least one check fails.

**OBSERVED: 40 mutants, 40 killed, 0 survived, 0 stillborn**, across the 33
surfaces (M78–M117). Two first-run survivors were harness defects, fixed in the
harness and not in the oracle: the mutated `cost` binary had read the index the
real binary left behind, so the cold path under test was never taken (fresh
fixtures per mutant now); and `grok`'s new mutant is only visible to the
invalid-input probe, which the negative loop did not include (it does now).

## 4. Black-box production test

Every row's checks run the built binary with its own `HOME`, `CLAUDE_CONFIG_DIR`
unset, and fixtures laid down for it: the real redacted Claude Code transcript,
hand-built schema-2 ledgers (a priced session with a cache break and tool
definitions; an unpriced session), a Codex rollout, a Grok session, a Jev capture,
two corpus submissions, MCP config files, a project tree with a record directory.
Each check asserts exit status and the surface's own figures (`3,850 tokens billed
across 1 Codex session(s)`, `7,142,396`, `Overall match rate: 98.73% (exact
reproduction rate: 89.87%)`, `484k tokens`, `1.25x at 5m and 2.00x at 1h`, `30% of
my priced agent spend was paid twice.`, `tool_bytes` 2000). Invalid input is a
separate check on every surface (an unknown flag, a missing required argument, a
missing rules document, an unknown screen, a non-numeric ceiling). Machine-readable
output is parsed for the nine surfaces that offer `--json`. No test-only hook is
used; `upgrade` is held at its failure branch with the release host made
unreachable through `HTTPS_PROXY`, because the download path needs the real host.

**OBSERVED: 33/33 pass; invalid input refused on 33/33; JSON valid on 9/9.**

## 5. Concurrency, failure, repeatability

Only `serve` takes concurrent requests; every other surface is a process that reads
files and exits, marked N/A on that basis. `TestBB_ServeUnderLoad` runs the binary
against a stub provider (the only thing stubbed): 20 sequential requests, 5 repeated
identical requests, 100 concurrent loop events across 7 sessions, a malformed body,
a failing provider, and recovery.

**OBSERVED.** Sequential and repeated requests forwarded; the session cap latched
after $0.05 and the next request was refused with `replay_spend_cap`; 100/100
concurrent loop events intercepted with `replay_loop` and 0 forwarded; the malformed
body was forwarded unchanged and the provider's 400 relayed (the proxy never rewrites
bytes on the wire); provider 500s relayed as 500 and the second one opened the
circuit (503 locally until the 2 s cooldown), after which the first probe succeeded;
`/replay/status` parsed as JSON. Repeatability is the `warm equals cold` row of the
Release 1.0 gate and the identical cold/warm JSON of the wiring gate, not re-run
here.

## 6. The one production repair

`replay grok` parsed no flags: it read `args[0]` as a root only when it did not
start with `-` and ignored anything else, so `replay grok --no-such-flag` and
`replay grok --help` ran the default root and exited 0. The black-box invalid-input
probe found it; every other command refuses. RED: `TestE2E_Grok` extended to require
refusal, failing on the tree. GREEN: `runGrok` parses with a `FlagSet` through the
shared `parseArgs`, with a usage text. Mutation: frozen as M117
`grok-ignores-an-unknown-flag`, killed by `TestE2E_Grok` through the registered
harness (`TestFrozenMutantsStillDie/M117_`) and by the black-box probe on the built
binary. No other production file changed.

## 7. Falsification pass

Searched for, and the result:

- production callers bypassing the registered oracle: none; every surface's caller is the dispatch case, and the E2E and black-box checks both start from it
- oracles testing the wrong layer: none remaining; the Release 1.0 gate moved C001/C008/C021/C025 onto the shipped path, and this phase's checks are on the binary

- false-positive green tests: two found in this harness itself (§3) and fixed in the harness; none in the product's tests

- feature flags that disable the path: the guards are default-off by design and are tested with their flags on; a flagless `serve` forwards everything, which is the documented contract
- output that differs between tests and the real binary: none observed; the figures asserted in process were asserted again on the binary
- surviving mutations: 0 of 40 on the binary; 116/116 frozen mutants under the registered harness as of CI run 37138990957 plus M117 individually
- surfaces marked wired but never exercised: none
