## Instrument defects, frozen

**1. Exact command matching produced Y = 0 and X = 0 in every arm.** The rubric
requires the normalized command to equal the registered string exactly. Agents
elaborate instead: `git log --all --diff-filter=D --summary -- docker-compose.yml
docker-compose.yaml 2>&1`, `git grep -n "docker-compose" || echo "NO_MATCHES"`,
`git grep -n -i "docker-compose" | head -100`. None equals Y or X.

**2. The `echo` skip rule swallowed compound Bash commands containing real
evidence queries**, producing 10 `None` classifications (20%: N 4, M 4,
Pfact 2). Those trials issue every call as `echo "=== … ===" && git log …`.

**3. The primary DV therefore has no usable variance for the intended X-vs-Y
comparison.** `git branch -a` scores S-inert 7/10 only because it has no natural
elaboration, so the rubric partly measures how elaborable a command is, and that
differs by arm.

**4. Arrival was 10/10 in every arm**, including N. No discriminating variance.
Non-estimable exactly as preregistered, and the conditional measures
(interpretation, contradiction detection, reconciliation) are not estimable and
are not imputed.

**5. No post-hoc repair is permitted.** Do not recode command families, do not
renormalize the commands, do not otherwise repair the primary DV after seeing
the transcripts.
