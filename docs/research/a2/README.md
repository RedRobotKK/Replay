# A2: task calibration

**Status: the declared candidate set is exhausted without a calibrated task.**
Control-arm only. No treatment arm ever ran against any A2 candidate, so nothing
in this directory is a mechanism result.

A2 asked one question: can a frozen, objectively scorable contradiction task be
built on which fresh-agent C0 detection lands between 40 and 70 percent? Gate A
had failed at ceiling, and the failure was in the task rather than the analysis.
